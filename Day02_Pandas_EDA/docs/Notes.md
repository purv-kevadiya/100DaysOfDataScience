# 📒 Day 02 Notes

## What is Pandas?

Pandas is an open-source Python library used for data manipulation and analysis.

It provides two main data structures:

- Series
- DataFrame

---

## What is a DataFrame?

A DataFrame is a two-dimensional table consisting of rows and columns.

Example

| Name | Age |
|------|----:|
| Amit | 24 |
| Riya | 26 |

## What is EDA?

Exploratory Data Analysis (EDA) is the process of understanding data before creating reports or machine learning models.

EDA helps us

- Find missing values
- Detect outliers
- Understand distributions
- Discover trends
- Prepare clean datasets

---

## Key Learning

Today's biggest lesson:

> Never start Machine Learning before understanding your data.

# Unit Testing

Unit testing checks whether individual functions behave correctly.

Benefits:
- Finds bugs early
- Makes refactoring safer
- Improves code quality
- Increases confidence in changes

Common assertion methods:
- assertEqual()
- assertTrue()
- assertFalse()
- assertIsInstance()
- assertGreater()
