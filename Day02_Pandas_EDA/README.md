## 📖 Project Overview

This project is part of my **#100DaysOfDataScience** challenge.

On Day 2, I focused on learning **Exploratory Data Analysis (EDA)** using **Pandas** by analyzing an E-Commerce Sales dataset.

The project demonstrates how to load, inspect, clean, analyze, and export structured business data using professional Python coding practices.
