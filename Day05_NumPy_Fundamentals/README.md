# 📖 Project Overview

Day 05 focuses on learning the fundamentals of **NumPy**, the core numerical computing library in Python. This project demonstrates how to work with NumPy arrays, perform mathematical operations, reshape arrays, calculate statistics, sort data, save arrays, and generate professional reports using a modular and production-ready project structure.

---

# 🎯 Objectives

- Learn NumPy arrays
- Understand ndarray properties
- Practice array creation techniques
- Perform indexing and slicing
- Reshape arrays
- Compute statistical measures
- Sort arrays efficiently
- Save arrays as `.npy`
- Generate automated reports
- Build a clean, modular Python project

# ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd Day05_NumPy_Fundamentals
```

Install dependencies:

```bash
pip install -r requirements.txt
```

# ▶️ Run the Project

```bash
python src/main.py
```
